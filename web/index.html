01 · Problem

Problem

Hand-chained training scripts waste accelerator hours when schema mismatches fail mid-job, unchanged upstream stages re-run from scratch, preempted workers corrupt checkpoints, or uncalibrated models ship without automated regression checks.

MLOps & Model Factory

Overview

SageFactory unifies workflow orchestration and long-running job resiliency into a single serverless control plane. Scientists author pipelines in a typed Python SDK or JSON specification, and Kahn's topological wave compiler checks cycles, cross-step schema types, tokenizer vocabularies, and 3D parallelism world sizes in 0.084 ms median before launching compute. During iterative experimentation, content-addressed SHA-256 Merkle keys memoize step outputs in SQLite WAL so unchanged upstream steps resolve in 0.213 ms median (a 5,551.6x speedup across the 4-step upstream build). For multi-rank training, monotonic lease_epoch tokens block delayed zombie workers while per-shard SHA-256 verification quarantines partial crash writes and resumes with exact parameter parity (max_abs_weight_diff = 0.0). Finally, a live Amazon Bedrock (us.amazon.nova-lite-v1:0) evaluation gate checks quality, latency, and safety refusal before promoting a candidate to canary or production traffic.

01 · LATE SCHEMA FAILURES

Broken Step Contracts Fail Hours Into a Job

Passing a CSV float32 table or mismatched tokenizer vocabulary into an FSDP or verl training stage crashes after cluster nodes spin up unless cross-step contracts are verified at compile time.

02 · REPEATED UPSTREAM WORK

Tweaking an Eval Rule Re-Runs Data Prep

Adjusting a downstream promotion threshold or evaluation prompt should not re-tokenize raw data or retrain unchanged adapter weights when upstream inputs and code AST have not changed.

03 · TORN SHARDS & ZOMBIES

Crashes and Preemptions Corrupt Checkpoints

A spot preemption mid-save leaves truncated rank shards on disk, and a delayed worker waking after a network stall can overwrite a newer checkpoint unless fenced by a monotonic epoch token.

04 · UNGATED PROMOTIONS

Manual Model Rollouts Miss Regressions

Promoting fine-tuned checkpoints without automated quality, tail-latency, and credential-safety checks risks routing production traffic to regressions with broken formatting or weak guardrails.

03 · Implementation

Implementation

SageFactory is structured as five cohesive Python 3.12 modules covering typed DAG compilation, content-addressed step caching, fenced multi-rank checkpointing, live Amazon Bedrock evaluation gating, and serverless API routing.

12 / 12 Unit Tests Passing
01 · TYPED PYTHON SDK & WAVE COMPILER sage_factory/pipeline_dag.py
Engineers author workflows in a typed Python SDK (@pipeline_step, DataPrepStep, FineTuneStep, BedrockEvalStep, ConditionStep, RegisterModelStep) or canonical JSON, keeping code and visual DAG views synchronized.
compile_pipeline_dag() parses Python recipes safely through ast.parse() without arbitrary code execution, runs Kahn's topological wave sort in 0.084 ms median, catches cycles, missing ports, dtype/column mismatches, and invalid TP * PP * DP accelerator topologies, and emits HyperPod PyTorchJob and RayJob YAML specs.
02 · SHA-256 STEP CACHE & LINEAGE GRAPH sage_factory/step_cache.py
Re-running a pipeline after changing a downstream threshold or adding code comments skips expensive upstream steps automatically, while changing upstream data invalidates every dependent stage cleanly.
compute_step_merkle_key() strips docstrings via an ast.NodeTransformer and hashes step_kind | code_ast_hash | params_hash | inputs_hash. SQLite WAL lookups finish in 0.213 ms median (5,551.6x faster than the 4,957.6 ms cold 4-step build) while recording parent-to-child artifact provenance edges.
03 · FENCED CHECKPOINT & SHARD RECOVERY sage_factory/fenced_checkpoint.py
Distributed training jobs write multi-rank state atomically and assign each active worker a strictly increasing lease epoch so delayed preempted workers can never overwrite newer progress.
FencedCheckpointEngine increments lease_epoch in SQLite WAL, commits 4-rank shards via two-phase os.replace() onto _COMMITTED_MANIFEST.json, verifies per-shard SHA-256 digests in 1.3 ms median, quarantines torn crash shards, and restores deterministic dataloader offsets with max_abs_weight_diff = 0.0.
04 · LIVE BEDROCK GATE & MODEL REGISTRY sage_factory/eval_registry.py · server.py
Candidate model configurations must pass a golden benchmark covering technical accuracy, structured JSON formatting, tail latency, and credential-leak refusal before advancing in the Model Registry.
BedrockEvalRegistry calls us.amazon.nova-lite-v1:0 via the Bedrock Converse API (436.5 ms median across 24 calls), evaluates ConditionStep thresholds, and records versioned transitions (PendingApproval -> Canary_10Pct -> Production or Rejected) with full dataset-to-endpoint lineage.
04 · Trade-Offs

Trade-Offs

Every architectural choice in SageFactory balances safety, deterministic reproducibility, and serverless operating cost against runtime flexibility.

Design Decisions
01 · AST PARSING VS ARBITRARY EXEC

Declarative AST Inspection Instead of Dynamic Python Exec

Parsing Python SDK snippets with ast.parse() and ast.literal_eval() restricts top-level pipeline definitions to declarative step constructors rather than arbitrary runtime loops. In return, compiling untrusted SDK edits in the browser is completely safe on shared serverless infrastructure and completes in 0.084 ms median.

02 · STRICT MERKLE INVALIDATION

Exact Content Hashing Over Approximate Semantic Caching

Binding normalized code AST, sorted hyperparameters, and upstream SHA-256 digests means any functional change to upstream dataprep forces downstream steps to re-execute. While stricter than manual cache overrides, this guarantees zero stale artifact drift between dataset versions and registered model packages.

03 · TWO-PHASE STEP ROLLBACK

Replaying Since Last Verified Checkpoint vs. In-Place Shard Repair

When a single rank crashes mid-write at step 9, SageFactory quarantines the entire unverified step directory and replays deterministic batches from step 6 rather than attempting partial cross-rank stitch recovery. Replaying a few steps trades minor recompute for mathematical certainty that all ranks stay synchronized (0.0 weight drift).

04 · SERVERLESS CONTROL PLANE

Lambda /tmp + SQLite WAL Demo vs. Persistent Multi-Node Storage

Running the live API on AWS Lambda with SQLite WAL and /tmp shard storage keeps idle cloud cost at $0.00 while exercising real file atomicity, SHA-256 verification, and live Bedrock calls. For multi-terabyte production runs, the same manifest compiler and fencing protocol target FSx for Lustre, S3 Express One Zone, and DynamoDB leases.
